# 对话归档（Conversations）

记录与各类 AI 的对话。每份对话一个文件，按 `_template.md` 格式归档。

## 归档规范

- 文件名：`YYYY-MM-DD-<主题关键词>.md`（如 `2026-11-01-github-ai-profile.md`）
- 只记录有长期价值的对话：重要决策、偏好形成、复杂任务；日常闲聊不必归档
- 归档前剔除敏感信息（见根目录 `AGENTS.md` 红线）
- 归档后在下表登记一行
