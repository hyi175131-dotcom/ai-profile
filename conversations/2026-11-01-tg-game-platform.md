# TG 小程序游戏平台「暗剑娱乐」开发全程

## 背景

主人要做一款 Telegram 群真人骰子吹牛小程序，随后逐步加需求：积分下注（USDT 充值、1 USDT = 100 积分、不可提现的娱乐积分）、语音聊天、管理后台，最终扩展到 3 款游戏并上线运营。全程由 Kimi Work 远程部署到主人的宝塔服务器（单机 Ubuntu 22）。

## 关键内容

**上线的 3 款游戏**

- 🎲 骰子吹牛（2-6 人）：每人 5 骰不减，只能往上叫，输家出局；劈/反劈机制（接受/反劈/拒绝，每劈一次翻倍，反劈最多 2 次，8 倍封顶）；飞/斋规则可选
- 🃏 跑得快（2-3 人）：48 张牌，黑桃 3 先出；三带二任意 2 张、四带三任意 3 张、末手可少带、连对 2 连起、顺子 5 张起、炸弹 ×2、春天 ×2；管不上自动「要不起」
- 🐂 牛牛（2-6 人）：52 张每人 5 张，3 张凑十 + 2 张定牛；牛八/牛九 ×2、牛牛 ×3；同牛比最大单张再比花色；发牌后 6 秒自动开牌结算；轮庄/通比/房主坐庄三模式

**技术决策**

- 后端 Node.js + Express + socket.io，游戏引擎分层（dice/cards/niuniu 各一引擎，房间管理器统一分发）
- 前端 Vue 3 + Vite，TG Mini App 深链分享（startapp=房间码直达准备页）
- LiveKit 实时语音（视频功能按主人要求后移除）；语音做长连优化
- 复式记账 ledger，余额变动全留痕 + 每日 crontab 自动对账；公平性用 commitHash/seed 公示，结算后可验牌
- 管理后台：TG ID + 一次性验证码登录；总览/分游戏数据卡/用户查询（含 TG ID）/封禁/调分/充值订单/房间管理/全量对账
- 群播报：绑定 TG 群，开局与终局战报推送 + 置顶引导消息带游戏按钮

**体验细节（主人逐项定制）**

- 骰盅为金属圆盖样式（刻「暗剑科技」），摇盅有声、上滑开盅后盖子消失
- 叫点用密码锁式滚轮选择；上家叫点女声播报给下家
- 输家乌鸦飞屏 +「倒霉蛋」语音；赢家金色彩带；劈战大刀闪电特效
- 每局结束留在房间展示战绩，点「返回继续」才回准备页

**排障记录**

- 修复「房间不存在或已解散」（重连找回错房间 → 优先返回进行中牌局）
- 修复「牌局未开始」误报、语音/视频频繁重连、视频窗口重复等问题
- 修复跑得快黑桃 3 首出误判；牛牛开发中修复终止房间误退底注、统计 SQL 联表计数放大
